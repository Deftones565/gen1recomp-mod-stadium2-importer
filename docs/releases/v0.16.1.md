# Gym arenas and scene routing fixes

**Full Changelog**: https://github.com/Deftones565/gen1recomp-mod-stadium2-importer/compare/v0.16.0...v0.16.1

No reimport needed.

# Changes

- **Gyms always use their Stadium gym arena**: every gym battle now shows
  that leader's Stadium 2 arena, ahead of the painted scenes and whether or
  not CONTEXT ARENAS is on. If the arena can't load, the painted gym scene
  is used instead. Gen 1's Cinnabar Gym now uses Blaine's arena. The
  Fighting Dojo, which has no Stadium arena, uses the painted gym. A TEST
  ENVIRONMENT setting still overrides this
- **Gen 1 rooms use the Interior scene**: houses, labs (including Oak's Lab
  for the first rival battle), marts, Pokemon Centers, gates and the
  Underground Path no longer fall back to the classic scene
- **Mt. Silver's exterior uses the Mountain scene** instead of Town

# Known Issues

- The new scenes have not been played on a phone yet; report any lag or
  anything that looks wrong

  Kenney scenes; still being investigated
- Beta: many moves have not been checked against the real game yet
- Hydro Pump's water is not visible
- Slowpoke and Slowbro have no hit reaction
