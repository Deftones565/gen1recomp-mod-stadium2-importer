# Stadium 2's battle UI

**Full Changelog**: https://github.com/Deftones565/gen1recomp-mod-stadium2-importer/compare/v0.16.3...v0.17.0

No reimport needed. Turn on **STADIUM UI** in the mod's options (needs BATTLE
HUD on).

# Changes

- **STADIUM UI option (new, off by default):** Stadium 2's own battle UI,
  with its textures and fonts read from your ROM, replaces the glass HUD in
  Gen 1 and Gen 2 battles:
  - Status panels with name, level, status, gender, HP bar and party balls
  - Live 3D portraits beside each panel, framed per species with the game's
    own camera data. Stadium draws them at 32x32; the mod draws them sharper
  - Stadium's message box and font
  - Command bar: BATTLE, POKeMON, RUN, plus PACK (a mod addition)
  - Move diamond with type colours and PP, and the move info card with
    power, accuracy and description
  - Switch cards for up to six Pokemon (Stadium teams have three; the second
    row is a mod addition)
  - Stadium's YES/NO window for questions such as switching, nicknames and
    learning moves
- **Controls:** with a controller the menus work like Stadium 2's:
  - A BATTLE, B POKeMON, START RUN, RB PACK
  - C buttons on the right stick pick moves and Pokemon
  - Hold the D-pad for a move's info
  - LB cancels
  - Right stick down shows the second row of switch cards
  - Holding RB while picking a Pokemon checks it
- **Keyboard and touch:** MENU CONTROLS `CURSOR` (default) keeps a
  moving cursor, marked with a yellow frame; left/right move along the
  command bar. I/J/K/L are the C buttons. Tap a tab, move, card or answer
  to pick it
- With STADIUM UI on, none of the glass HUD shows through any more
- Gen 1: Absorb no longer plays Leech Seed's drain
- Hydro Pump confirmed drawing

# Known Issues

- Stadium UI is new: it matches the decomp and ROM data but has not been
  compared with the real game on every screen
- Portrait lighting is not decoded yet; a neutral light is used
- Button icons are always the N64's, whatever controller you use
- Jynx's 7th animation leaves only its hair on the ground; this matches the
  ROM data but has not been compared with the real game
- Some effects can look turned relative to the Pokemon in Classic and
  Kenney scenes; still being investigated
- Beta: many moves have not been checked against the real game yet
- Stadium sounds are not played
