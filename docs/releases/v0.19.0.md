# Stadium UI now the Stadium 2 UI mod; evolution camera; phone layout

**Full Changelog**: https://github.com/Deftones565/gen1recomp-mod-stadium2-importer/compare/v0.18.0...v0.19.0

No reimport needed.

# Changes

- **STADIUM UI is now the Stadium 2 UI mod, included:** the option runs the
  same UI as the standalone [Stadium 2 UI](https://github.com/Deftones565/Stadium-2-UI)
  mod (v1.0.3), so both get every UI improvement:
  - the PACK, item use on a Pokemon, the level-up stats card and an EXP bar
  - the UI art and font are painted in code instead of read from the ROM
    (live 3D portraits still use Stadium's camera data from your ROM)
  - on phones, portrait uses the whole screen (cards and menus above the
    game, the message box with room) instead of hiding most of the UI
  - your existing MENU CONTROLS, UI DETAIL and CONTROLLER ICONS settings
    carry over
  - if you also have the standalone mod installed, only one draws
- **Evolution in battle:**
  - the camera goes to the front of the Pokemon
  - it no longer jumps up and down while the two forms trade places; it
    swings round the Pokemon smoothly and sways gently
- **Fixed:** the white strip cutting your Pokemon's back sprite on phones
  (normal Game Boy battle scene, Stadium 2 UI)

# Known Issues

- The in-battle evolution has not been checked in every case (Gen 1 and
  Gen 2, cancelled, a Pokemon that was not out)
- Portrait lighting is not decoded yet; a neutral light is used
- Beta: many moves have not been checked against the real game yet
- Stadium sounds are not played
