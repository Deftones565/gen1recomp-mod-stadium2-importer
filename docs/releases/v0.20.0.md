# Stadium UI is now the separate Stadium 2 UI mod (required)

**Full Changelog**: https://github.com/Deftones565/gen1recomp-mod-stadium2-importer/compare/v0.19.1...v0.20.0

No reimport needed.

# Changes

- **The Stadium UI is no longer built into this mod.** It is the
  [Stadium 2 UI](https://github.com/Deftones565/Stadium-2-UI) mod (1.1.0 or
  newer), which this mod now requires. When you install or update, the game
  offers to download it. If the importer shows **Incompatible** in the mod
  list, Stadium 2 UI is installed but switched off: switch it on (or switch
  the importer off and on again, which turns it on too).
  - The UI is on as soon as that mod is enabled. Its options (STADIUM UI,
    MENU CONTROLS, UI DETAIL, CONTROLLER ICONS) are in the Stadium 2 UI
    mod's settings, not here; set them again there if you had changed them.
  - UI fixes now arrive as Stadium 2 UI updates, without an importer update.
    Stadium 2 UI 1.1.0 also fixes the whole UI going missing on some phones.
- The in-battle evolution's texts use the Stadium 2 UI mod's message box.
- **Fixed: Pokemon invisible in KENNEY NATURE scenes on some phones**
  (woodland, cave, town and lake). The scene's torch, lamp and firefly
  lighting stopped the model from drawing when the phone's graphics driver
  had dropped a lighting value the shader does not use; each value is now
  checked, and a lighting problem can no longer hide a Pokemon.
