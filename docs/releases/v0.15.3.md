# Graphics settings and 3D scene speed

**Full Changelog**: https://github.com/Deftones565/gen1recomp-mod-stadium2-importer/compare/v0.15.2...v0.15.3

Aimed at phones. No reimport needed.

# New

- **GRAPHICS**: set to SHOW to list the graphics settings in the mod's
  options: SHADER STYLE, 3D RESOLUTION, BATTLE AA, PARTICLES and SCENE
  WEATHER. HIDE just hides the rows; your settings still apply
- **3D RESOLUTION** (AUTO / 100% / 75% / 50%): resolution of the 3D battle
  scene only. The game's text and menus stay sharp. AUTO keeps PC at full
  resolution and caps phones and tablets at about 1920x864 worth of pixels,
  which makes the Kenney scenes (woodland, cave, freshwater, town) run much
  smoother. The 3D scene looks a little softer on phones; pick 100% if you
  prefer it sharp, or 75%/50% if it still lags
- **PARTICLES** (ON / OFF): OFF hides move-effect particles (sparks,
  bubbles, Poke Ball bursts) for speed on slow phones. Effect timing is
  unchanged. This is a mod option, not something the original game has

# Fixes

- Town and freshwater scenes: fixed a wrong fallback path for their
