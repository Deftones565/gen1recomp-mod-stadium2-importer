# Changes

- **Fixed: crash on start after updating the mod without restarting the
  app** (`main.lua:35 attempted to call field 'setMessageClaim'`, seen on
  phones). The game kept the previous version's code loaded; the mod now
  reloads all of its own code when its version changes
- **CONTROLLER ICONS option (new):** the Stadium UI's button prompts can
  show your controller's buttons instead of the N64's:
  - `AUTO` (default) detects the controller you last used
  - `XBOX`, `PLAYSTATION`, `AYN THOR` or `STEAM DECK` picks a family by hand
  - `NATIVE N64` keeps Stadium 2's own icons
  - Keyboard play shows the N64 icons under `AUTO`
- **THOR INPUT MODE:** for the AYN Thor, match its controller style so the
  A/B and X/Y prompts line up with the buttons
