# Switched-in Pokemon visible again

**Full Changelog**: https://github.com/Deftones565/gen1recomp-mod-stadium2-importer/compare/v0.16.2...v0.16.3

No reimport needed.

# Changes

- **Pokemon sent out after a switch had no model** (most visible with POKE
  BALL off): the return effect's fade-out carried over to the next Pokemon.
  Each newly sent-out Pokemon now starts fully visible, as in Stadium. Gen 1
  and Gen 2, both sides
- **POKE BALL OFF also turns off the return effect** when you switch
  Pokemon

# Known Issues

- Jynx's 7th animation leaves only its hair on the ground; this matches the

- Some effects can look turned relative to the Pokemon in Classic and
  Kenney scenes; still being investigated
- Beta: many moves have not been checked against the real game yet
- Hydro Pump's water is not visible
- Stadium sounds are not played
