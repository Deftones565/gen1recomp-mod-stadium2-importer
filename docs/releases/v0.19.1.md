# POKE BALL off by default; switch-out fix; Stadium 2 UI 1.0.4

**Full Changelog**: https://github.com/Deftones565/gen1recomp-mod-stadium2-importer/compare/v0.19.0...v0.19.1

No reimport needed.

# Changes

- **POKE BALL (send-out / return animation) is now off by default.** Turn it
  on in the options if you want it.
- **Fixed (Gen 2):** after a ball was thrown, a Pokemon switched out later
  could shrink, and sometimes stay invisible. The shrink now only happens
  while the ball-throw animation is actually playing.
- **STADIUM UI updated to [Stadium 2 UI 1.0.4](https://github.com/Deftones565/Stadium-2-UI/releases/tag/v1.0.4):**
  - all six Pokemon on the switch screen have buttons, using the game's own
    layout (B, C-left, C-up / A, C-down, C-right)
  - a STATUS card: hold R and hold a Pokemon's button, or long-press it
    on a touch screen
  - L CANCEL / R CHECK tabs; the cursor in CURSOR controls can pick CANCEL
  - touch: long-press a move for its info, and tap to close it
  - Gen 1 move info shows Stadium 2's move descriptions; Gen 2 move text
    no longer shows `<NEXT>`
  - PACK moves one row per press

# Known Issues

- The in-battle evolution has not been checked in every case (Gen 1 and
  Gen 2, cancelled, a Pokemon that was not out)
