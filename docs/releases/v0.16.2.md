# Android model fix and Pokemon model fixes

**Full Changelog**: https://github.com/Deftones565/gen1recomp-mod-stadium2-importer/compare/v0.16.1...v0.16.2

Models are re-imported automatically on first launch (a progress screen shows).

# Changes

- **Pokemon invisible on some Android phones**: models showed only their
  shadows because the model shader failed to build on strict GPU drivers.
  Fixed for every game and scene
- **Politoed and Ursaring**: body parts no longer look detached; parts drawn
  from joints defined later in the model now use the right joint. Chinchou,
  Lanturn, Girafarig, Delibird, Phanpy, Tyrogue and Larvitar change too
- **Grimer and Muk**: slime body, mouth, tongue and Muk's eyes now match the
  original game
- **Slowpoke and Slowbro hit reaction**: animations now come from each
  model's own animation table in the ROM (also Articuno, Exeggutor, Xatu,
  Sudowoodo)
- **Articuno's last animation** no longer plays garbage
- **Diglett and Dugtrio Dig animations**: heads now hide underground and pop
  up as in the game. Animations of about 45 other species now use their
  exact ROM bone scales (for example Hoppip's petals)
- **Pineco's eyes** draw correctly from every side
- **README**: shorter, with screenshots; developer notes moved to
  docs/INTEGRATION.md

# Known Issues

- Jynx's 7th animation leaves only its hair on the ground; this matches the
  ROM data but has not been compared with the real game
- Some effects can look turned relative to the Pokemon in Classic and
  Kenney scenes; still being investigated
- Beta: many moves have not been checked against the real game yet
- Hydro Pump's water is not visible
- Stadium sounds are not played
